# Sound files

Audio files are not included. You must add these three mp3 files to this folder:

- `correct.mp3` (correct key press)
- `wrong.mp3` (mistake)
- `game-over.mp3` (game over screen shown)

Vite serves them at `/sounds/correct.mp3`, `/sounds/wrong.mp3`, and `/sounds/game-over.mp3`.

The game keeps working without sound if a file is missing.
